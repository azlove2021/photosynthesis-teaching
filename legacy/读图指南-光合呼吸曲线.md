# 这张图怎么看 —— 光合 / 呼吸曲线读图指南

> 配套课件：`photosynthesis-teaching.html`（双击即可，断网可用）
> 适用：高中生物「光合作用与细胞呼吸」第二课时，以及高三一轮复习的图表专题
> 本文所有数字都取自课件里同一个模型（25 ℃、400 ppm CO₂、21% O₂、整株）

---

## 一、先记住一句话

> **这张图上只有一条线是"测得到"的——蓝色实线（净光合）。另外两条都是它的解释，不是它的同伴。**

学生看图出问题，九成不是数学问题，是没弄清"哪条是真的、哪条是算的"。把这句话先钉住，后面全顺。

---

## 二、图上到底画了什么

### 2.1 三条主线（必须分清）

| 线 | 长什么样 | 它是什么 | 怎么来的 | 能不能直接测 |
|---|---|---|---|---|
| **净光合** | 深蓝→浅蓝**实线**，带一点辉光 | 箱子里 CO₂ 的**净变化**：造出来的减掉烧掉的 | 就是传感器读数 | ✅ **唯一能直接测的** |
| **总光合** | 绿色**虚线**（短划） | 叶绿体**一共造了**多少有机物 | 净光合 **＋** 呼吸，算出来的 | ❌ 永远测不到，只能算 |
| **呼吸** | 琥珀色**水平虚线**，右端标「呼吸 2.1（只随温度变）」 | 植物**一共烧了**多少有机物 | 由温度决定，暗处测一次即可 | ✅ 间接可测（暗处读数） |

关键关系只有一条：

```
净光合 ＝ 总光合 − 呼吸
```

而呼吸在这张"速率—光强"图上**是一条水平线**，所以：

```
任意光强下，绿色虚线与蓝色实线的垂直间距 ＝ 呼吸 ＝ 2.1（25 ℃）
```

这个间距**从头到尾一样宽**。这是全图最重要的一件事，第四节会反复用它。线上没画箭头（原因见 5.2），讲的时候用手指或激光笔在两条线之间平移一遍，比画箭头更有说服力。

还有一个很好用的"三线同点"：琥珀色水平虚线会在 I ≈ 43 处**穿过绿色虚线**，而那里正是蓝色实线**穿过零线**的地方——**光补偿点**。三个现象同一个横坐标，说的是同一件事：此刻**总光合刚好等于呼吸**，所以净值恰好为零。

### 2.2 辅助元素（认得就行，别当主角）

| 元素 | 含义 | 学生最容易误会成 |
|---|---|---|
| **浅蓝细虚线 + "15℃ / 35℃"** | 温度对照的"鬼影线"，只有在你切温度时才显形 | 以为是别的植物的曲线 → 其实是**同一株**在别的温度下 |
| **红色圆点 + "光补偿点"** | 净光合正好等于 0 的那个光强 | 以为植物"停止光合了" → 是两笔账**刚好扯平** |
| **绿色圆点 + "光饱和点"** | 再加光也基本不再增益的位置 | 以为到这里光合"满了、到顶了" → 是**瓶颈换了人** |
| **空心圆 + 序号** | 你自己点「记录此刻」存下的实测点 | 以为是程序画的花纹 → 这是"曲线是测出来的"的证据 |
| **灰色空心圆** | 在**别的条件**（换过温度 / 口径 / 浓度）下测得的点 | 以为图算错了 → 条件变了点就不该跟着动，这才对 |
| **实心蓝点 / 红点** | 当前工作点（你正拖到的那个光强） | —— |
| **浅红底纹（零线以下）** | "净消耗"区：放出的比吸进去的多 | 以为"这里没有光合" → 有光合，只是不够花 |
| **右上角"加光不再增益"** | 饱和点右侧那一段的注脚 | —— |

## 三、为什么必然长这样（一句话模型）

光反应那一步是"按光量子收费"的，光越强，单位时间收到的能量越多，所以曲线起步是**接近直线的陡坡**；但暗反应的处理能力（酶的量、CO₂ 的供应）是有限的，于是曲线**越走越平**，最后贴着一条水平的天花板。

课件里用的是教材图表常用的**直角双曲线**，不是随手画的样条——所以"陡坡—拐弯—贴顶"这三段的形状是自洽的，学生拿尺子量斜率也能量出"越来越小"。

而呼吸这一项**根本不进这条公式**：它只跟温度走（Q₁₀＝2，温度每升 10 ℃ 翻一倍），光强从头到尾不参与计算。这是模型的设计，不是简化失误。

## 四、随光强增加，一段一段看

下面用默认条件（25 ℃、整株、400 ppm）走一遍。你可以把课件的光强滑杆从 0 拖到 2000，对着看。

### 段一 · 暗处到微光（I = 0 → 约 40）

- 总光合（绿虚线）**从 0 起步**：没有光，光反应停，整条链子断掉，一个有机物都造不出来。
- 呼吸（琥珀水平线）**照样在 2.1**：它烧的是现成的有机物，不看光。
- 所以净光合是 **−2.15**，蓝实线落在零线**下方**，箱内 CO₂ 在**上升**。

> 学生常问："没光它还呼吸？"——把灯关掉，读数不是变成 0，而是变成 −2.1。负号本身就是呼吸存在的证据。

### 段二 · 光补偿点（I ≈ 43）

- 蓝实线**穿过零线**，红点标出位置。
- 此刻总光合 ≈ 呼吸 ≈ 2.1，两笔账**刚好扯平**，箱内读数**一动不动**。
- 植物忙得很，只是进出相等。

> 这是全图最容易被误讲的一处：**"读数不动"≠"生理停止"**。此刻光合速率和呼吸速率都接近 2，谁都没停。

### 段三 · 上升段（I ≈ 43 → 约 1200）

- 蓝实线**快速上升**，斜率一路变小（这是"越来越吃力"的图形语言）。
- 绿虚线始终在蓝实线**上方**，两条线的间距**一直是 2.1**——你可以拿手指比一下，从头到尾没变宽过。
- 这一段的限制因素是**光**：加光就增产，投入产出比最高。

### 段四 · 饱和点之后（I ≳ 1270）

- 蓝实线**几乎水平**。从 1300 拖到 2000，净光合只从 22.7 涨到 23.4，涨了不到 3%。
- 绿虚线同样贴顶。间距还是 2.1。
- 限制因素**换人了**：不再是光，而是暗反应的酶和 CO₂ 供应。多加的光用不上，只会变成热。

> 注意：呼吸**没有变大也没有变小**，还是 2.1。这一点在这一段最好讲——因为"光合已经加不上去了，呼吸还在照常扣钱"，这正是净光合封顶的直接原因。

### 速查表（25 ℃、整株，可直接抄到黑板上）

| 光强 μmol·m⁻²·s⁻¹ | 总光合 | 净光合 | 呼吸 | 读法 |
|---:|---:|---:|---:|---|
| 0 | 0.0 | −2.15 | 2.15 | 只花钱不挣钱 |
| 20 | 1.0 | −1.15 | 2.15 | 开始造了，还不够花 |
| **43** | **2.1** | **0.0** | 2.15 | **光补偿点**，收支平衡 |
| 100 | 4.9 | 2.7 | 2.15 | 净积累开始 |
| 400 | 17.0 | 14.8 | 2.15 | 陡坡段，加光最划算 |
| 800 | 23.2 | 21.0 | 2.15 | 拐弯处 |
| **1270** | **24.8** | **22.7** | 2.15 | **光饱和点**，开始贴顶 |
| 2000 | 25.5 | 23.4 | 2.15 | 再加光基本无用 |

三个温度下的临界点对比（同一株、整株）：

| 温度 | 呼吸 | 光补偿点 | 光饱和点 | 最大净光合 |
|---|---:|---:|---:|---:|
| 15 ℃ | 1.07 | ≈ 22 | ≈ 850 | 16.1 |
| **25 ℃** | **2.15** | **≈ 43** | **≈ 1270** | **23.4** |
| 35 ℃ | 4.30 | ≈ 88 | ≈ 1150 | 18.8 |

这张小表本身就够讲一节课：

- **温度升 → 呼吸涨 → 补偿点右移**（要更多光才追得平）。补偿点由呼吸决定，呼吸由温度决定。
- **35 ℃ 的饱和点反而比 25 ℃ 靠左**，因为光合酶已经过了最适温（28 ℃），处理上限降下来了。这是"高温使光合下降"的图形证据，也是高考常设的陷阱。

## 五、这张图有没有错

分三层说，越往后越值得讲。

### 5.1 模型本身：没错

- 光强为 0 时总光合 = 0、呼吸 ≠ 0 ✔
- 呼吸只随温度变、与光强无关 ✔（Q₁₀＝2）
- 净光合 = 总光合 − 呼吸，处处成立 ✔
- 补偿点由呼吸与初始斜率共同决定，随温度右移 ✔
- 饱和点之后曲线贴顶，限制因素转移 ✔

### 5.2 但**画法**上曾经有一处真缺陷（已修）

你截图那一版里，图上**没有把呼吸画成一条线**，只在你当前停留的那个光强处，画了一小段"两条曲线之间的间距"，旁边写"呼吸"两个字。

结果就是：**这段标注随着你拖光强一路往上跑**。学生（和听课的老师）看到的是一个跟着光强往上移动的琥珀色标记，理所当然地读成"呼吸随着光强增加而增加"——**这是纯粹的图形误导，不是模型算错**。

中间还试过两版改进，都没成，一并说清楚，免得以后又绕回去：

- **改成双向箭头**：2.1 在这根纵轴（−8 到 30）上只有约 11 像素，而工作点的圆点直径就有 12 像素，箭头和"呼吸"两个字被圆点整个吃掉，放大八倍才看得见一个像素点。
- **改成两曲线之间的淡色带子**：理论上最直观（带宽＝呼吸），但 11 像素宽的带子压在带辉光的粗蓝线上，投影时根本看不出"等宽"。

最后采用的做法只有两件，都经得起投影：

1. 加了一条**贯穿全图的琥珀色水平虚线**，右端直接写「呼吸 2.1（只随温度变）」。平的事实一眼可见。
2. 撤掉了工作点旁那段间距标注——呼吸的数值由这条线说，"总光合 − 呼吸 = 净光合"由右栏的三量对账说，图上不再重复第三遍。

> 顺带说一句：这个"看图看出来的错误"，本身就是这节课最好的教学点。一个学生能指着图说"这里不对"，说明他在用模型检验图形，而不是背图形。

### 5.3 五个常见误读，逐条对

| 误读 | 错在哪 | 一句话纠正 |
|---|---|---|
| ① 呼吸随光强增加 | 把"随光强移动的标注"当成了曲线 | 呼吸是水平线；只看温度 |
| ② 净光合就是"光合作用的量" | 净是差值，漏掉了被当场烧掉的那份 | 净 = 总 − 呼吸；总才是"造了多少" |
| ③ 绿虚线是测出来的 | 没有任何仪器能直接测总光合 | 总光合永远是净光合加回去算的 |
| ④ 零线以下没有光合 | 负号只说明支出大于收入 | I = 20 时总光合已有 1.0 |
| ⑤ 两条曲线是两个独立过程 | 它们共用同一个 gross | 绿线往下平移 2.1 就是蓝线 |

第 ⑤ 条值得在黑板画一次：**把绿虚线整体往下推 2.1，正好落在蓝实线上**。图形上一推，比讲十句都管用。

## 六、四个可调条件，各带动什么

课件能改的不只光强。每改一个，图上动的部分完全不同——这正好是"控制变量"的现场演示。

| 调什么 | 呼吸线 | 绿虚线（总光合） | 蓝实线（净光合） | 补偿点 | 一句话 |
|---|---|---|---|---|---|
| **光强** | 不动 | 沿曲线走 | 沿曲线走 | 不动 | 只改"走多远"，不改"路在哪" |
| **温度** | **整条上下移** | 天花板的**高度**变 | 整体**平移** | **左右移** | 呼吸变，两线的间距就变 |
| **CO₂ 浓度** | 不动 | 天花板变高/变低 | 同步变 | 略移 | 直接改"处理能力" |
| **口径（整株/叶片）** | 小幅下移 | **完全不动** | 整体上移 | 略左移 | 只减掉根茎那份呼吸 |

口径那一条要专门强调：**总光合曲线不随口径变，变的是呼吸那一份**。整株与叶片在 I = 800 处的净光合差 0.47，就是根和茎的呼吸（只花钱不挣钱）。课件右栏有一行分解说明会实时显示这个差值。

## 七、做题时怎么落到这张图上

题干出现这些词，直接对应图上的位置：

| 题干说法 | 图上位置 |
|---|---|
| "净光合速率" / "表观光合速率" / "CO₂ 吸收速率" | **蓝实线**的读数 |
| "总光合速率" / "真光合速率" / "CO₂ 固定速率" / "有机物制造速率" | **绿虚线**的读数 |
| "开始积累有机物" / "不再向外释放 CO₂" | **光补偿点**（蓝线穿零） |
| "光合速率不再随光强增加而增大" | **光饱和点**右侧 |
| "黑暗中的 CO₂ 释放量" | **呼吸**（= 零线到蓝线起点的距离） |
| "植物"（未指明部位） | **整株**；写"叶片"才是叶片 |

两条最容易失分的规则：

1. **先圈主语**（植物 / 叶片），再看问的是净还是总。
2. **总光合永远要"加回去"**：题目只给净值和暗处读数时，答案 = 净值 + 暗处读数。

## 八、课件里的两个新东西

### 8.1 语音讲解（离线）

顶栏「讲解」按钮，或按 **V** 开关。开启后：

- 切题（← →）、点「记录此刻」、展开化学式抽屉，都会**自动读对应那一段**，不用再点播放。
- 底部会出现一条**字幕**，后排听不清也能看。
- 按 **Esc** 立刻掐掉当前这句（读错、被打断时用）。
- 用的是系统自带的语音合成，**不联网**。机器上没装中文语音包时，会自动降级成**只出字幕**，并如实告诉你——不会假装能读。

### 8.2 呼吸水平线

就是 5.2 里说的那处改动。上课时可以直接指着那条琥珀色水平线问一句：

> "这条线为什么是平的？"

这个问题答对了，这一节的核心就过了。

紧接着还可以追问第二个——它比第一个更狠：

> "那这条线为什么在左边跑到绿色虚线**上面**去了？"

因为 I 很小的时候总光合还不到 2.1，呼吸照旧扣 2.1，所以净值是负的。**这正是补偿点之前"入不敷出"的图形解释**，也是"负号不等于没有光合"最直接的证据。

净光合 = 总光合 − 呼吸          ← 一切换算的根
