一 · 光合作用总反应
6CO2 + 6H2O 光能·叶绿体 C6H12O6 + 6O2
把水写全的式子：6CO2 + 12H2O → C6H12O6 + 6O2 + 6H2O。 它说明 O₂ 里的氧全部来自水，葡萄糖里的氧来自 CO2。
二 · 光合的两个阶段
光反应 · 类囊体薄膜上
H2O 光能、色素 NADPH（即 [H]） + O2
ADP + Pi 光能 ATP
暗反应 · 叶绿体基质中
CO2 + C5 酶 2C3
2C3 + NADPH + ATP 酶 (CH2O) + C5
光反应把 NADPH 和 ATP 交给暗反应；暗反应把 ADP、Pi 和 NADP+ 还回去。所以"暗反应不直接需要光"不等于"没有光也能长久进行"—— 停了光反应，它很快就没原料了。
三 · 有氧呼吸三个阶段（还原氢写作 [H]）
① 细胞质基质
C6H12O6 酶 2 丙酮酸 + 4[H] + 少量能量
② 线粒体基质
2 丙酮酸 + 6H2O 酶 6CO2 + 20[H] + 少量能量
③ 线粒体内膜
24[H] + 6O2 酶 12H2O + 大量能量
C6H12O6 + 6O2 + 6H2O 酶 6CO2 + 12H2O + 能量
只有第三阶段消耗 O2。O2 的作用是接受 [H] 生成水， 不是直接去和葡萄糖反应。CO2 只在第二阶段产生。
四 · 能量去哪了
1 mol 葡萄糖彻底氧化分解 → 释放 2870 kJ
其中 1161 kJ 储存在 ATP 中，其余以热能散失。 教材不要求记 ATP 的个数，只要求记住这两个数字和"大部分以热能形式散失"。
五 · 无氧呼吸（作对照）
C6H12O6 酶 2C3H6O3（乳酸） + 少量能量
C6H12O6 酶 2C2H5OH + 2CO2 + 少量能量
无氧呼吸只在第一阶段产生少量 ATP，有机物分解不彻底。
六 · 和本页模型的关系
· 本模型只算有氧呼吸，不计无氧呼吸；ATP 只作过程示意，不标个数。
· 光合与呼吸同时进行、互不停歇。曲线上的"净光合"只是两者相减的净结果： 净积累 / 净消耗 / 恰好抵消，不是"一个开、一个关"。
· 光强为 0 时总光合为 0、呼吸不为 0；这与"光合一停呼吸就停"是两件事。
